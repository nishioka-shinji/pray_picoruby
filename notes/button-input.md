# ボタン入力

GP16 にタクトスイッチ、GP17 に LED を繋いで、`src/button_led.rb`（押している間だけ点く）と `src/button_toggle.rb`（押すたびに切り替わる）を動かした。配線図は `notes/wiring-diagrams.md` を見る。

## 結論

| 項目 | 値 |
|---|---|
| 入力の作り方 | `GPIO.new(16, GPIO::IN \| GPIO::PULL_UP)` |
| 読み方 | `button.low?` が押している状態（プルアップなので押すと 0） |
| ボタン側の抵抗 | 不要（Pico 内蔵のプルアップを使う） |
| チャタリング | 20ms ごとに読むだけで、トグルが 2 回切り替わることはなかった |

## タクトスイッチの刺し方

- このブレッドボードは中央の溝（e と f の間）が広く、タクトスイッチをまたがせて刺せない。片側（f〜j）の中に収める
- 足は向かい合う 2 つの面から 2 本ずつ出ている。向かい合う面どうしの足（間隔が広い）は中で繋がっていて、同じ面の 2 本（間隔が狭い）を押すと繋がる
- 正しい刺し方は f40 / i40 / f42 / i42（3 穴幅を列方向、2 穴幅を行方向）
- f–h（2 穴幅）に刺すと、間隔の狭い足が列方向に入って向きが 90° ずれる。中で繋がっている足が 40 行目と 42 行目にまたがるため、押していなくても LED が点きっぱなしになった
- 向きが分からないときは、適当に刺して試し、点きっぱなしなら 90° 回せばよい
