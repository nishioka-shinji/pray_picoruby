# 手持ちの部品

Freenove Basic Starter Kit for Raspberry Pi Pico（型番 FNK0064A、Amazon B09XHTHZ8N）を使っている。Pico は無線なしの無印。チュートリアルとコードは `~/Downloads/Freenove_Basic_Starter_Kit_for_Raspberry_Pi_Pico-main/` にダウンロード済み。
