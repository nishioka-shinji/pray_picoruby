# アナログ入力（ADC）

可変抵抗 B10K の真ん中の足を GP26 に、両端を 3V3 と GND に繋ぎ、つまみの位置を読んだ。配線図は `notes/wiring-diagrams.md` を見る。

| 項目 | 値 |
|---|---|
| require | `require 'adc'`（R2P2 に最初から入っている） |
| 作り方 | `ADC.new(26)` |
| 使えるピン | GP26・GP27・GP28 の 3 本だけ |
| 読み方 | `read_raw` で 0〜4095（12 ビット）。`read_voltage` なら 0.0〜3.3 の電圧 |
| 電源 | 3V3 は Pico の右側 5 行目（ピン 36）。2 行上の VSYS は 5V 近いので繋がない |

- 何も繋いでいないピンを読んでもエラーにはならず、でたらめな値が出る。ADC が使えるかの確認だけなら、配線の前にできる
- 値で 2 つの状態を切り替えるときは、しきい値を 2 つに分ける（2300 を超えたら上、1800 を下回ったら下）。1 つだと、境目の小さな揺れで行ったり来たりする
